# Changelog

## 0.1.5 (20) - 2026-11-05

- Install DirectSide from the current official release without a separate IPA download.
- Preserve the selected device during downloads and keep custom IPA installation under **+**.
- Fix the Windows taskbar icon and improve download progress and version labels.

## 0.1.4 (19) - 2026-11-01

- Renew expired LiveContainer installations without opening or deleting LiveContainer.
- Restore a missing LiveContainer renewal package and recover relocated cache paths.
- Keep renewal tied to the existing application and signing team.
- Show app-specific guidance when a renewal IPA is missing.

## 0.1.3 (18) - 2026-10-26

- Show pending source updates, available versions and per-source update counts.
- Add native pull-to-refresh indicators, including short views.
- Refresh open app/source details and improve version/build comparisons.

## 0.1.2 (17) - 2026-10-25

- Update TLS, certificate, networking and archive dependencies.
- Improve IPA archive validation and release package checks.

## 0.1.1 (16) - 2026-10-25

- Improve guided Windows setup, USB recovery and developer-team trust instructions.
- Display app versions on both platforms.
- Simplify settings, source import and installed app management.
- Add iPhone self-updates, imported signing identities and LiveContainer certificate setup.

## 0.1.0 - 2026-10-24

- Initial Windows and iPhone applications with local Apple authentication.
- USB setup, app sources, IPA import and signature renewal.
- Optional LiveContainer integration and English/German settings.
